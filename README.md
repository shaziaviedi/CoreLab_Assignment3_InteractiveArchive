# Elsewhere

- **Elsewhere is a React website with an interactive 3D memorial scene.**
  - React manages the interface and user actions.
  - Three.js draws the models, lighting, and animations.

- **`index.html` and `src/main.jsx` start the website.**
  - `index.html` provides the container for the app.
  - `main.jsx` loads `App.jsx` and the CSS.

- **`src/App.jsx` manages the overall experience.**
  - Displays the landing page, fragment menu, instructions, and photo archive.
  - Remembers which fragments are placed and which camera view is active.
  - This information is stored in **state**, which acts as the app's memory.

- **`src/World3D.jsx` assembles and controls the 3D scene.**
  - Positions the objects, controls the camera, and manages day/night transitions.
  - Receives information from `App.jsx` through **props**—information passed from a parent component to a child.

- **Separate files under `src` handle the scene's objects.**
  - `UploadedArchitecture.jsx`: background buildings, One World Trade Center, and Oculus.
  - `SkylineLayout.js`: background building positions.
  - `ReferenceMuseum.jsx`: museum model and appearance.
  - `ReferencePool.jsx`: pool model, colors, and reflected highlights.
  - `WaterfallParticles.jsx`: animated falling water.
  - `TexturedTree.jsx`: trees, bushes, and the survivor tree.
  - `ParkLawns.jsx`: grass patches.
  - `CelestialModels.jsx`: sun, moon, and their glow.

- **Two files work together to animate pedestrians.**
  - `PedestrianPaths.js` calculates walking routes and standing positions.
  - `AnimatedVisitor.jsx` controls walking and idle animations and keeps feet grounded.
  - `World3D.jsx` connects their movement to the observation data.

- **Shaders create the environmental effects.**
  - Shaders are small programs that run on the graphics card.
  - `AtmosphericHaze.jsx` softens the skyline seam.
  - `EnchantedEnvironment.jsx` adds light rays and floating sparkles.
  - `DreamySurfaceLight.jsx` adds highlights to model surfaces.
  - Other shaders create clouds, stars, and water effects.

- **`src/style.css` styles the interface.**
  - Controls text, menus, buttons, spacing, and Polaroid cards.
  - The 3D objects are styled through materials, lighting, and shaders.

- **The data files supply the research observations.**
  - `observations.json` stores the imported observations.
  - `data.js` calculates rounded averages and provides values for the data cards and pedestrian system.

- **Interactions follow a simple chain.**
  - The user places a fragment.
  - `App.jsx` updates its state.
  - Updated props reach `World3D.jsx`.
  - The scene changes to match.

- **`useFrame` handles continuous animation.**
  - Runs updates every rendered frame.
  - Moves pedestrians, advances water particles, and animates environmental effects.

- **The folders have different purposes.**
  - `src`: editable application code.
  - `public`: assets such as uploaded 3D models.
  - `dist`: the finished website generated by `npm run build`.

- **Captured photos currently stay in memory.**
  - They appear in the archive during the session.
  - Refreshing the page clears them.
